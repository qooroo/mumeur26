# 老妈欧洲游26

Planning and trip log for L's solo Europe trip, **7–27 September 2026**.

**📖 [View the itinerary](https://qooroo.github.io/mumeur26/)**

London → Paris → Florence → Rome → Athens → Hydra → home. 20 nights.

| | Dates | Nights |
|---|---|---|
| Paris | Mon 7 – Sat 12 Sep | 5 |
| Florence | Sat 12 – Wed 16 Sep | 4 |
| Rome | Wed 16 – Mon 21 Sep | 5 |
| Athens | Mon 21 – Thu 24 Sep | 3 |

| Athens (buffer night) | Sat 26 – Sun 27 Sep | 1 |

## In this repo

- **`index.html`** — the day-by-day itinerary, published via GitHub Pages.
  Self-contained: no external fonts or CDNs, so it works offline on a phone
  while travelling. The booking checklist saves ticks in the browser.
- **`docs/superpowers/specs/`** — the design spec: why the trip is shaped
  this way, rejected alternatives, costs, and open questions.
